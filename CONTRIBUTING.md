# Contributing

## Rules

1. **No secrets** in commits, issues, or examples (use placeholders and OOB Secret recipes).
2. **Pin versions** in any install snippet after looking up latest stable upstream.
3. Prefer small, focused changes: one topic per PR when the repo is public.
4. Keep docs and matching `skills/*/SKILL.md` in sync.
5. English is the default for technical docs; optional `docs/pt/` summaries are welcome.

## Local skill install

```bash
bash scripts/install-skills.sh --both
```

## Style

- Imperative, short, testable steps
- Tables for decisions; diagrams in ASCII or Mermaid
- Link skills from setup docs and `docs/MAP.md`
