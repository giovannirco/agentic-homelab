# Português (resumo)

Este repositório é o caminho **homelab + agentes de IA → engenharia de plataforma**.

1. Leia [../00-philosophy.md](../00-philosophy.md) (inglês — termos técnicos de entrevista).
2. Siga a ordem em [../setup/](../setup/) (01 → 10).
3. Instale skills no Hermes: `bash scripts/install-skills.sh --hermes`
4. Use o board de issues como currículo vivo.
5. Lições duras: [../lessons/hard-won.md](../lessons/hard-won.md)

**Ideia:** Kubernetes é a estrada. GitOps, CNI, tunnel e o agente (Hermes) andam nela. A IA multiplica se você der skills + permissões certas — não se você só der cluster-admin.

Canal de aprendizado: “estou aprendendo platform” → o agente explica o *porquê* enquanto executa o *como*.
